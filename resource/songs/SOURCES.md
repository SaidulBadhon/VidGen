# Bundled background music

Every file in this directory is dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Random BGM
picks from here (and from tracks you upload in the UI). Drop extra audio files
in this folder, or upload them from Settings / the book render panel.

These replace the original MoneyPrinterTurbo pack, which was audio ripped from
YouTube videos and was not safe to ship.
